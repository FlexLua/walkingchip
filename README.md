## 项目一：手机遥控

<img src="pic/IMG_2724.webp" alt="手机遥控" width="360">

### 项目介绍

通过手机蓝牙 App / 小程序上的「遥控按钮组合」小控件，遥控行走芯片运动（前后左右）。

**项目视频：** https://www.bilibili.com/video/BV1mptg6LE5g/

**需满足如下条件才能实现本项目：**

1. 准备好 CPU-302 及相关配件
2. App 上勾选「终端」，并在终端页面添加「遥控按钮组合」控件

### 前置描述

```
我做了一个“行走的芯片”，M0电机和M1电机用来控制它运动，电机驱动时用最大功率。M0M1控制“行走的芯片”运动的规则如下:
“行走的芯片”左转：M0反转，M1反转
“行走的芯片”右转：M0正转，M1正转
“行走的芯片”前进：M0反转，M1正转
“行走的芯片”后退：M0正转，M1反转

玩具芯片还接了9颗WS2812彩色灯珠。

DS9激光测距L0-L7这八个测距传感器每两个一组，顺时针均匀分布在正方形的四边，L0和L1分别对着正前方，L2和L3对着右方，L4和L5对着后方，L6和L7对着左。如果传感器值无效就不参与判断。
```

### AI 词条 1

```
我想通过手机遥控“行走的芯片”前进、后退、左拐、右拐
```

### AI 词条 2

```
“上”按钮按下的时候，向前运动3秒，
“下”按钮按下的时候，后退运动3秒，
“左”按钮按下的时候，连续10秒向左运动转圈，
“右”按钮按下的时候，连续10秒向右运动转圈，
```

## 项目二：多路激光障碍测距，躲避障碍

<img src="pic/IMG_2745.webp" alt="激光避障" width="360">

<img src="pic/DS9.webp" alt="DS9" width="360">

### 项目介绍

通过增加 9 路激光测距模块，感知附近出现的物体，并主动避开（向反方向运动）。

**项目视频：** https://www.bilibili.com/video/BV1zztg6eEee/

**实现本项目需满足如下条件：**

1. 准备好 CPU-302 以及相关配件
2. App 上勾选节点：DS9（9 路激光测距模块，每路测距范围约 1 米）

### 前置描述

```
我做了一个“行走的芯片”，M0电机和M1电机用来控制它运动，电机驱动时用最大功率。M0M1控制“行走的芯片”运动的规则如下:
“行走的芯片”左转：M0反转，M1反转
“行走的芯片”右转：M0正转，M1正转
“行走的芯片”前进：M0反转，M1正转
“行走的芯片”后退：M0正转，M1反转

另外还连接了 DS9 激光测距传感器，L0-L7这八个测距传感器每两个一组，顺时针均匀分布在正方形的四边，L0和L1分别对着正前方，L2和L3对着右方，L4和L5对着后方，L6和L7对着左。如果传感器值无效就不参与判断。
```

### AI 词条 1

```
帮我实现代码，四个方向上的激光测距传感器如果在30厘米范围内感知到障碍物，则“行走的芯片”向反方向运动。
```

### AI 词条 2

```
我想实现一个可以自动避障的“行走的芯片”，上电后默认向前运动，并在运动的过程中自动避开离自己自己越来越近的障碍物。如果上方有物体靠近且在15厘米范围内，那么芯片加速向左或者向右运动（取决于左右哪边更空旷）。
```

## 项目三：增加彩色灯珠「尾巴」

<img src="pic/IMG_2781.webp" alt="彩色灯珠尾巴" width="360">

### 项目介绍

激光测距模块感知附近出现的物体，根据物体的方位以及距离，调整彩色灯珠的数量和颜色。

**项目视频：** https://www.bilibili.com/video/BV1fztg6eEk3/

**实现本项目需满足如下条件：**

1. 准备好 CPU-302 以及相关配件
2. App 上勾选节点：DS9（九路激光测距模块，每路测距范围约 1 米）

### 前置描述

```
我给“行走的芯片”连接了9颗WS2812彩色灯珠。

另外还连接了 DS9 激光测距传感器，L0-L7这八个测距传感器每两个一组，顺时针均匀分布在正方形的四边，L0和L1分别对着正前方，L2和L3对着右方，L4和L5对着后方，L6和L7对着左。如果传感器值无效就不参与判断。
```

### AI 词条 1

```
我希望四个方向的传感器在30厘米范围内感应的距离越近灯珠亮的数量越多，不同方向颜色不一样，每次只显示一种颜色，颜色取距离最近的那个方位。
```
